# M322_Project - Mindtrap

Ein HTML-basiertes Designprojekt für das Modul M322. Dieses Projekt enthält Design-Konzepte, Styleguides und einen interaktiven Prototypen für das Projekt "Mindtrap".

## 📁 Projektstruktur

### Dateien
- **mindtrap_prototyp.html** - Interaktiver Prototyp der Mindtrap-Anwendung
- **Mindtrap_Styleguide.html** - Umfassender Styleguide mit Design-Elementen und Komponenten
- **Mindtrap_Moodboard.html** - Moodboard zur visuellen Inspiration und Design-Richtung
- **Mindtrap Moodboard Collage.html** - Erweiterte Moodboard-Kollagen mit visuellen Referenzen
- **README.md** - Diese Datei

## 🎨 Projekt-Übersicht

Mindtrap ist ein designorientiertes Projekt, das die folgenden Komponenten umfasst:

### Styleguide
Der Styleguide definiert alle visuellen Standards, Farben, Typografie und UI-Komponenten für das Projekt.

### Moodboard
Das Moodboard bietet eine visuelle Orientierung und zeigt die Design-Inspiration und Ästhetik des Projekts.

### Prototyp
Der interaktive Prototyp demonstriert die praktische Umsetzung der Design-Konzepte.

## 🚀 Nutzung

1. **HTML-Dateien öffnen**: Alle Dateien können direkt im Browser geöffnet werden
2. **Styleguide konsultieren**: Für Design-Richtlinien und Komponenten
3. **Prototyp testen**: Den Prototyp nutzen, um die Funktionalität zu erleben

## 💻 Technologie

- **HTML5** - Markup-Sprache für alle Komponenten
- **CSS** - Styling und Designumsetzung
- **JavaScript** - Interaktivität im Prototyp

## 📝 Modul

Dieses Projekt wurde für das Modul M322 erstellt.
